## 📖 Sobre o Projeto

**Guardião Firewall** é um jogo 2D educativo e interativo desenvolvido para o **Concurso 2026 Dev Game CCXP Educação (Framework ARCADE)**, alinhado à temática **"Programadores do Amanhã"**: *quem constrói tecnologia precisa saber proteger as pessoas*.

Na história, a **Rede Kyber** está sob um ataque massivo de Invasores digitais. Assumindo o papel da nova Guardiã Firewall — com o auxílio da IA mentora **R2-DEF** —, o jogador deve passar por diferentes setores do sistema para aprender, na prática, conceitos fundamentais de cibersegurança, proteção de dados e privacidade.

---

## 🕹️ Fases e Mecânicas

O jogo é dividido em 4 atos progressivos que combinam reflexos, tomada de decisão e batalhas dinâmicas:

1. **Ato 1 — Construção de Senha Forte:** Monte credenciais complexas combinando blocos de caracteres (letras, números e símbolos) para transformar tentativas de invasão por força bruta de segundos em milênios.
2. **Ato 2 — Caça ao Golpe (Phishing):** Analise remetentes e mensagens sospeitas em tempo real, classificando-as rapidamente entre `[GOLPE]` ou `[SEGURO]`.
3. **Ato 3 — Proteção de Dados e Permissões:** Avalie solicitações de acesso de aplicativos na loja da Rede Kyber e bloqueie permissões abusivas que ameaçam a privacidade.
4. **Ato 4 — Confronto Final contra O Invasor (Estilo *Undertale*):** Um combate de turnos dinâmico onde o jogador controla o **Cadeado Escudo** dentro de uma arena, desviando de enxurradas de *spams*, vírus e links maliciosos enquanto responde a *quizzes* de cibersegurança para zerar a barra de ameaça do vilão.

## 🛠️ Tecnologias Utilizadas

* **[Phaser 3](https://phaser.io/):** Framework principal para desenvolvimento de jogos 2D em HTML5.
* **[Vite](https://vitejs.dev/):** Ferramenta de empacotamento (*bundler*) e servidor de desenvolvimento rápido.
* **Python, JavaScript (ES6+), HTML5 & CSS3:** Lógica das cenas, física Arcade, UI e estilização.
* **Pixel Art & Chiptune/Synthwave:** Estética visual sob medida e trilhas sonoras/efeitos com controle de volume integrado.

## 🚀 Como Rodar o Projeto Localmente

Caso queira executar ou modificar o código-fonte no seu computador:

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/melissavitor/questgirls.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd questgirls
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. Acesse o endereço local exibido no terminal (geralmente `http://localhost:5173`).
